## One-page business case

📌 Nate Nasralla's approach: write it "Mad Lib" style, live with the champion, in the buyer's language.
It answers three things: problem, cost of inaction, and why now.

```
BUSINESS CASE — {Company} × RAMPED                         Owner: {Champion}

1. THE PROBLEM (in our words)
   Today, {team} {situation}. This causes {operational problem}, which means {executive impact}.

2. COST OF INACTION
   If nothing changes in the next {12} months: {$ / hours / risk / missed goal}.
   How we calculated it: {simple math the CFO can check}.

3. WHY NOW
   {Event / deadline / initiative} on {date} requires this to be solved by {date}.

4. WHAT WE'RE DOING ABOUT IT
   Approach: {1–2 sentences}.  Alternatives considered: {status quo / build / vendor X}.

5. SUCCESS METRICS (90 days / 12 months)
   - {Metric 1}: from {X} to {Y}
   - {Metric 2}: from {X} to {Y}

6. INVESTMENT
   {Price, term}. Payback: {months}.

7. PLAN & OWNERS
   See close plan. Executive sponsor: {name}.
```

## Scorecards (1 = miss · 2 = partial · 3 = solid · 4 = elite)

### Cold call certification rubric (C2)

| Line | 1 | 4 | Score |
|---|---|---|---|
| Opener | Uses "bad time?" or a generic line | Uses context, owns the cold call, and the delivery lands | |
| Tone | Rushed or apologetic | Calm and warm, with a pattern interrupt | |
| Problem proposition | Pitches features or a product category | Vivid problem in the buyer's words, then a one-line differentiator | |
| Objection: acknowledge | Argues or ignores it | Pauses, then validates genuinely | |
| Objection: clarify | Skips this step | Brings out the real objection | |
| Wax back | Re-pitches the same thing | Tailors the pitch to what they said | |
| Close | No ask, or a vague one | Assumptive, with specific times or a placeholder invite | |
| **Coachability** (second attempt) | No change | Applies the feedback right away | |

### Discovery certification rubric (C3)

| Line | 1 | 4 | Score |
|---|---|---|---|
| PPO agenda | No agenda | Purpose, plan and outcome are stated and the buyer adds to them | |
| Situation | Interrogates | Brief, uses "typically", shows research | |
| Operational problem | Stays on the surface | Gets to frequency, consequences, what they've tried | |
| Executive impact | Not reached | Quantified, and tied to an exec's goal | |
| Question craft | Closed questions | Uses humbling disclaimers and "to what extent…" | |
| Looking for trouble | Avoids risk | Asks proactively what could stop the deal | |
| 5-Minute Drill | Skipped | Covers want, when and how; asks about the last purchase | |
| Next steps | "I'll follow up" | Next meeting booked live, and next-next step agreed | |

### Negotiation certification rubric (C6)

| Line | 1 | 4 | Score |
|---|---|---|---|
| Power confirmed before trading | No | Confirms the person can sign by the date | |
| Vendor of choice + timeline locked first | No | Both confirmed before any trade | |
| Price delivery | Rambles or justifies | Explains structure, states the price, then silence | |
| Flinch | Concedes immediately | Shows genuine surprise and holds | |
| Give-for-get | Free discount | Every concession is traded for a lever (volume, cash timing, term, deal timing) | |
| Slip clause | None | "If the date slips, pricing returns to standard" | |
